# Investigation Screenshots

This directory contains visual evidence collected during the phishing email investigation lab.

## Evidence Categories

### 1. Email Header Analysis

Evidence of SPF, DKIM and DMARC authentication checks performed using Google Admin Toolbox.

### 2. URL Analysis

VirusTotal URL reputation analysis and security vendor detection results.

### 3. Domain and Infrastructure Analysis

Domain-related investigation, IP address information, ASN details and network ownership observations.

## Investigation Notes

All screenshots are intended to demonstrate the investigation workflow and analytical process.

The project uses simulated phishing email evidence. Screenshots must not be interpreted as proof of a live phishing campaign.
